# Alan Jr. Ecalnir | Personal Portfolio

CSE 316 final project. A static portfolio site with a featured software engineering case study (CCSRMS).

- Live site: https://alan-ecalnir-portfolio.vercel.app
- Case study page: https://alan-ecalnir-portfolio.vercel.app/case-study.html

## Stack

Plain HTML, CSS, and JavaScript. No build step and no dependencies.

## Project structure

```
index.html        Home page (intro, about and skills, work, contact)
case-study.html   Featured case study: CCSRMS
style.css         Shared styles
main.js           Typing effect and the draggable 3D computer
nav.js           Mobile menu, scroll effects, and screenshot viewer
assets/           Photo and CCSRMS screenshots
```

## Run locally

1. Clone the repository.
2. Open the folder in VS Code and run **Open with Live Server** on `index.html`, or open `index.html` directly in a browser.

## Deployment

Hosted on Vercel from the `main` branch of this repository. Framework preset: Other. No build command.

## Accessibility

Skip link, semantic landmarks, alt text on images, visible keyboard focus, and reduced-motion support. The 3D computer can be rotated with the arrow keys.
